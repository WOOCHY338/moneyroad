# 머니로드 (MoneyRoad)

1만 원으로 시작하는 모의 주식 게임. 단일 HTML 파일이라 서버도 빌드도 필요 없습니다.

## 플레이

`index.html`을 브라우저로 열면 바로 시작됩니다. GitHub Pages로 배포하면 링크만 공유하면 됩니다.

## 기능

| 구분 | 내용 |
|---|---|
| 로그인 | Google 계정 로그인 + 게스트 로그인. 계정별로 저장 슬롯이 분리됩니다 |
| 저장 슬롯 | 계정당 6칸. 이어하기 / 삭제 / 총자산 순위 표시 |
| 국내주식 | 삼성전자 · 삼양식품 · 카카오 · 네이버 · SK하이닉스 · 현대차 |
| 해외주식 | 엔비디아 · 애플 · 월마트 · 마이크로소프트 · 테슬라 · 아마존 · 라이엇게임즈 (환율 변동 적용) |
| AI 속보 | 30초마다 헤드라인 자동 생성. 종목 / 섹터 / 거시 / 초대형 4종이 주가를 실제로 움직입니다 |
| 은행 | 신용대출(한도 = 순자산 × 2), 신용등급 5단계, DAY별 이자, 마진콜 강제청산 |
| 배속 | 일시정지 / 1x / 2x / 4x / 8x. 단축키 `Space` `1` `2` `4` `8` |

시드머니 10,000원. 1틱 = 1초, 20틱 = 1 DAY. 등락 색상은 한국식(상승 빨강 / 하락 파랑)입니다.

## 설정

둘 다 비워두면 게임은 그대로 동작합니다. Google 버튼은 설정 안내를 띄우고, 광고 자리에는 자체 배너가 돌아갑니다.

### Google 로그인

`index.html` 안의 `GOOGLE_CLIENT_ID`에 클라이언트 ID를 넣으면 켜집니다.

1. [console.cloud.google.com](https://console.cloud.google.com) → API 및 서비스 → 사용자 인증 정보
2. 사용자 인증 정보 만들기 → **OAuth 클라이언트 ID** → 웹 애플리케이션
3. **승인된 JavaScript 원본**에 배포 주소를 등록 (예: `https://<사용자명>.github.io`)
4. 발급된 ID를 `GOOGLE_CLIENT_ID`에 붙여넣기

```js
const GOOGLE_CLIENT_ID = '';   // ← 여기
```

> 브라우저에서 JWT를 디코딩해 이름과 이메일만 읽는 방식입니다. 서버 검증이 없으므로 수업·데모용으로만 쓰세요.

### 배너 광고 (AdSense)

`ADSENSE` 값을 채우면 자체 배너 대신 실제 광고 단위가 들어갑니다.

```js
const ADSENSE = { client:'ca-pub-...', slotTop:'...', slotBottom:'...' };
```

> AdSense는 승인된 도메인에서만 노출됩니다. 로컬 파일(`file://`)에서는 보이지 않습니다.

## 저장 방식

진행 상황은 브라우저 `localStorage`에 계정별 키로 저장됩니다 (`MONEYROAD_SAVE_V1:<계정>`).
같은 브라우저에서만 이어집니다. 저장소가 차단된 환경에서는 경고만 뜨고 플레이는 정상 동작합니다.
